# 차트 기능 검증

## 검증 대상
카테고리별 매출 차트와 주문 상태별 주문 수 차트

## AI 제안 코드
Matplotlib을 사용하여 2개의 막대 차트를 구현하였다.

- 카테고리별 매출
- 주문 상태별 주문 수

## 검증 방법
1. Streamlit 화면에 차트 2개가 출력되는지 확인하였다.
2. 카테고리 필터를 변경하였다.
3. 주문 상태 필터를 변경하였다.
4. 필터 선택에 따라 차트가 변경되는지 확인하였다.

## 검증 결과
두 개의 차트가 정상적으로 표시되었다.

필터를 변경하면 차트도 선택한 데이터에 맞게 변경되었다.

## 수정 사항
처음에는 차트가 너무 크게 표시되어 figsize=(7, 4)를 적용하였다.
또한 한글이 네모로 표시되어 한글 폰트 설정을 추가하였다.
