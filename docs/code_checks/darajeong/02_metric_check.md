# 사이드바 필터 검증

## 검증 대상
카테고리 및 주문 상태 필터

## AI 제안 코드
Streamlit sidebar의 selectbox를 사용하여 카테고리와 주문 상태를 선택하도록 구현하였다.

## 검증 방법
1. 카테고리를 '전체'로 선택하였다.
2. 특정 카테고리를 선택하였다.
3. 주문 상태를 변경하였다.
4. 카테고리와 주문 상태를 동시에 선택하였다.
5. 지표와 표의 결과가 선택한 조건에 따라 변경되는지 확인하였다.

## 검증 결과
카테고리와 주문 상태를 변경하면 지표와 표가 함께 변경되는 것을 확인하였다.

두 필터를 동시에 선택했을 때도 두 조건이 모두 적용되었다.

## 수정 사항
주문 상태 컬럼을 처음에는 status로 예상했으나 실제 컬럼명이 order_status인 것을 확인하여 수정하였다.
