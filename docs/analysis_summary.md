# 분석 결과 요약

## 1. 분석 목적

주문(`orders`), 주문 상세(`order_items`), 상품(`products`) 데이터를 병합하여 쇼핑몰의 주요 주문 지표와 매출 현황을 확인했다.

분석 과정에서는 주문 상세 금액을 계산하고, 전체 주문 수와 주문 수량, 총 주문 금액, 평균 주문 금액을 계산했다.

또한 상품 카테고리별 매출, 주문 상태별 주문 건수, 월별 주문 금액을 집계했다.

## 2. 데이터 병합 .

`order_items`와 `orders`를 `order_id` 기준으로 병합하고, 이후 `products`를 `product_id` 기준으로 추가 병합했다.

병합 전 `order_items`의 행 수는 14,603행이었으며, 병합 후에도 14,603행으로 유지되었다.

주문 날짜, 주문 상태, 상품명, 카테고리 등의 주요 컬럼에 결측치가 발생하지 않는 것도 확인했다.

## 3. 주문 상세 금액 계산

각 주문 상세의 금액은 다음과 같이 계산했다.

`item_amount = quantity × unit_price`

계산 결과는 첫 번째 행을 기준으로 직접 계산한 예상값과 실제 `item_amount` 값을 비교하여 검증했다.

## 4. 핵심 지표

분석 결과 주요 지표는 다음과 같다.

- 전체 주문 수: 6,000건
- 총 주문 수량: 23,596개
- 총 주문 금액: 1,837,774,300원
- 평균 주문 금액: 약 306,296원

평균 주문 금액은 주문 상세 행의 평균이 아니라, `order_id`별 주문 금액을 먼저 합산한 뒤 주문 단위로 평균을 계산했다.

## 5. 카테고리별 매출

상품 카테고리별로 `item_amount`를 합산하여 매출을 비교했다.

가장 높은 매출을 기록한 카테고리는 `생활가전`이며, 매출액은 457,423,100원으로 확인되었다.

카테고리별 매출 합계를 다시 더한 값과 전체 주문 금액이 일치하는 것도 검증했다.

## 6. 주문 상태별 주문 건수

주문 상태별 주문 건수를 계산했다.

병합된 데이터는 주문 상세 기준이기 때문에 동일한 `order_id`가 여러 번 나타날 수 있다.

따라서 `order_id`와 `order_status`의 중복을 제거한 뒤 상태별 고유 주문 수를 계산했다.

## 7. 월별 주문 금액

`order_date`를 날짜 형식으로 변환하고, 연-월 단위의 `order_month` 컬럼을 생성했다.

이후 월별로 `item_amount`를 합산하여 기간별 매출 변화를 확인했다.

월별 매출 합계와 전체 주문 금액이 일치하는 것도 검증했다.

## 8. 함수화

Notebook에서 직접 실행하고 검증한 계산 로직을 `src/analysis.py`에 함수로 정리했다.

주요 함수는 다음과 같다.

- `calculate_total_orders()`
- `calculate_total_quantity()`
- `calculate_total_sales()`
- `calculate_average_order_amount()`
- `get_category_sales()`
- `get_status_counts()`
- `get_monthly_sales()`

함수 실행 결과와 Notebook에서 직접 계산한 결과가 동일한지 확인했다.

## 9. 분석 결과 해석

제공된 데이터를 통해 전체 주문 규모와 매출 현황을 확인할 수 있었다.

특히 카테고리별 매출을 비교했을 때 생활가전의 매출이 가장 높았으며, 주문 상태별 분포와 월별 매출 변화도 확인할 수 있었다.

이를 통해 쇼핑몰의 기본적인 주문 및 매출 현황을 파악할 수 있다.

## 10. 분석 한계

이번 분석은 제공된 실습용 샘플 데이터만을 사용했기 때문에 실제 쇼핑몰의 시장 상황을 그대로 반영한다고 보기 어렵다.

또한 할인, 프로모션, 광고비, 상품 원가, 재고, 고객 유입 경로 등의 정보가 포함되어 있지 않다.

따라서 특정 카테고리 또는 특정 월의 매출이 높거나 낮은 원인을 정확하게 판단하기는 어렵다.

월별 매출 변화 역시 계절성이나 이벤트 등의 추가 정보가 없기 때문에 매출의 증감은 확인할 수 있지만 그 원인까지 설명하는 데에는 한계가 있다.

## 11. 검증 요약

분석 과정에서 병합 전후 행 수, 주문 금액 계산, 카테고리별 매출 합계와 전체 매출 합계를 비교하여 결과의 정확성을 확인했다.
